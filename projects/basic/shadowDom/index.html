🛡️ Shadow DOM 面试知识点梳理

1. 基础概念：open vs closed 模式

Shadow DOM 为元素创建一个独立的 DOM 子树，open 模式可通过 element.shadowRoot 访问，closed 模式返回 null。

2. 样式隔离

    
Shadow DOM 外的 CSS 规则不会渗入内部（外部→内部隔离），内部的样式也不会泄漏到外部（内部→外部隔离）。这是 Shadow DOM 最核心的应用价值。

3. Custom Element + Shadow DOM

    
Custom Elements 与 Shadow DOM 结合是最常见的 Web Component 模式 — 一个封装了结构、样式和行为的独立组件。

    

      将鼠标悬停在这里查看
      另一个 Tooltip 实例
      

        
my-tooltip 内部结构（已经封装在 Shadow DOM 中）：

        
<template id="tooltip-template">
  <style>
    .tooltip { ... }   /* 完全隔离，不影响外部 */
    .tooltip-text { ... }
  </style>
  <span class="tooltip">
    <slot></slot>          /* 投影外部内容 */
    <span class="tooltip-text"></span>
  </span>
</template>

      

    

  


  
  

    
4. Slot 插槽机制：投影 vs 嵌套

    
Slot 让外部内容被投影（project）到 Shadow DOM 内部。与 iframe 的"嵌套"不同，slot 是"投影"——内容仍属于 Light DOM，只是渲染位置在 Shadow DOM 中。

⬅️ Slot（投影）

          
    
            
  • 内容属于 Light DOM
    • 
            
  • 外部样式对投影内容生效
    • 
            
  • 内容在父级文档中可访问
    • 
          

        

        

          
iframe（嵌套）

          
    
            
  • 内容属于 独立文档
    • 
            
  • 完全隔离，外部样式无效
    • 
            
  • 跨文档通信需 postMessage

5. 事件重定向（Event Retargeting）

    
Shadow DOM 内部触发的事件在冒泡到外部时，event.target 会被重定向为 shadow host 元素，以保持封装性。

6. Shadow DOM 特有 CSS 特性

    

      

        

        

          
关键 CSS 伪类 / 伪元素：

          

            
:host选中 Shadow Host 本身

            
:host-context(selector)根据外部上下文选择 host

            
::slotted(selector)选中投影到 slot 的内容

            
::part()暴露 shadow 内部的元素供外部样式化

          

        

      

    

  


  

  

    
📋 面试核心要点总结

    

      
概念要点

      
Shadow DOM 是什么DOM 封装 + CSS 隔离 + 事件重定向，Web Component 三大标准之一

      
open vs closedopen 可通过 .shadowRoot 访问；closed 返回 null（浏览器内部常用，如 <video>）

      
样式隔离外部 CSS 不进入 Shadow DOM；内部 CSS 不泄漏到外部；可继承属性仍可穿透

      
slot 机制投影（projection）不是嵌套——内容属于 Light DOM，渲染在 Shadow DOM

      
事件重定向Shadow DOM 内部事件冒泡到外部时，target 被重定向为 host 元素

      
CSS 伪类:host :host-context() ::slotted() ::part()

      
适用场景Web Components、设计系统、第三方嵌入组件、微前端隔离
